# Elite — Account Deletion Page

The public account-deletion request page for the Elite habit tracker
(`com.eliteapp.tracker`), required by Google Play's account-deletion policy
(and referenced from App Store Connect's privacy section).

One static, self-contained page — `index.html` (brand mark embedded, no
external requests, no scripts). Deployed on Vercel; the production URL goes
into Play Console → App content → Data safety → Account deletion.

Source of truth: `Elite app/docs/release/account-deletion-page.html` in the
private app repo — edit there, copy here, redeploy.
